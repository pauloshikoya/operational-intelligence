# Operational Intelligence Platform

A real-time supply chain anomaly detection and AI narration system.
Ingests live commodity price and logistics data, detects statistical
anomalies using three complementary methods, and generates structured
intelligence reports using Claude.

## What It Does

Monitors global supply chain signals in real time:
- **6 commodity prices** — crude oil (WTI/Brent), natural gas, copper, wheat, aluminum
- **4 logistics hubs** — Rotterdam, Shanghai, Houston, Suez weather disruption scores

When an anomaly is detected, the system generates a structured intelligence
report explaining what changed, likely causes with confidence levels,
recommended actions, and explicit caveats about data limitations.
